# Drone First Responder ROI Simulator

A theoretical ROI and first-arrival simulator for police departments considering a Drone-as-First-Responder (DFR) program.

## Project Overview

This application helps police chiefs estimate the coverage, response times, emergency-call share, and potential cost savings of deploying a drone as a first responder. It provides a visual map, calculates a first-arrival model, dynamically generates an ROI comparison for 1, 3, and 5 years, and can email a finalized report.

## Features

- **Location Search:** Uses OpenStreetMap to geocode and center a coverage area.
- **Coverage Map:** Interactive map displaying the theoretical coverage circle based on radius.
- **Response-Time Comparison:** Calculates drone response time vs. benchmark patrol response time.
- **First-Arrival Model:** Estimates what percentage of total emergency calls the drone could respond to first, based on eligibility, coverage, and availability.
- **Program Economics & ROI:** Full interactive cost breakdown comparing the drone program against status quo patrol dispatch costs, syncing data from the simulation.
- **Email Report:** Sends a summarized theoretical report via email.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, React Leaflet, Lucide React
- **Backend:** Node.js, Express, Nodemailer

## Local Setup

### 1. Backend Setup

```bash
cd server
npm install
```

Create a `.env` file in the `server` directory (DO NOT commit this file). You must provide the following variables:

```
PORT=5001
FRONTEND_URL=http://localhost:5173
GEOCODER_CONTACT_EMAIL=your_email@example.com
EMAIL_USER=your_gmail_address@gmail.com
EMAIL_PASS=your_gmail_app_password
```

Start the backend:

```bash
npm start
```

### 2. Frontend Setup

```bash
cd client
npm install
```

Create a `.env` file in the `client` directory (DO NOT commit this file). You must provide the following variable:

```
VITE_API_URL=http://localhost:5001
```

Start the frontend:

```bash
npm run dev
```

## API Endpoints

- `GET /api/location?q=<address>` - Address geocoding
- `POST /api/response-time` - Calculates drone response times
- `POST /api/call-simulation` - Runs the first-arrival call distribution model
- `GET /api/roi/assumptions` - Fetches the planning estimates and sourced benchmarks
- `POST /api/roi/calculate` - Calculates one-time costs, annual costs, and 1,3,5-year ROI
- `POST /api/report/email` - Sends the final report summary via email

## Methodology

### Response-Time Methodology
Calculates drone flight time based on straight-line distance, plus a fixed launch delay. The result is compared against a fixed priority-1 patrol response time benchmark.

### Call Simulation Methodology
Assumes uniform geographic call distribution to calculate theoretical coverage percentage (area of coverage circle). Applies manual user inputs for drone eligibility and availability to estimate the total share of calls where the drone could arrive first.

### ROI Methodology
Combines one-time costs (drones, docks, setup) and annual costs (software, maintenance, staff) into a drone program cost. Estimates patrol savings by assuming a portion of drone-first arrivals resolve the call without a patrol car dispatch. Calculates the net benefit (Savings - Drone Program Cost).

## Sources & Limitations

**Disclaimer:** The results generated by this tool are **planning estimates only** and should not be used as guaranteed operational outcomes.

- **Patrol Response Benchmark:** The default 8.6-minute benchmark is sourced from the Chula Vista Police Department (2022). It is not a universal response time.
- All cost metrics (drone hardware, staffing, maintenance) are placeholder planning estimates and must be replaced with accurate department data and vendor quotes.
- The coverage map assumes a perfect theoretical circle, ignoring airspace restrictions, geography, and weather.

## Deployment Information

The project is structured to deploy smoothly:
- **Frontend** can be deployed to Vercel/Netlify. Ensure `VITE_API_URL` points to the deployed backend URL.
- **Backend** can be deployed to Render/Heroku. Ensure `FRONTEND_URL` is set to the frontend deployment URL to configure CORS correctly. Provide all email/geocoder variables securely in the environment settings.

## Security Note

**Never commit your `.env` files.** The repository includes `.gitignore` configurations to prevent accidental commits of environment secrets. Use an app-specific password for `EMAIL_PASS`, not your main email password.
